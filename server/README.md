# 🚀 Meynaa Logistics Backend (خادم منصة ميناء اللوجستية الذكية)

خادم متكامل تم بناؤه بأحدث المعايير الهندسية (Node.js + Express + TypeScript + Prisma ORM + Socket.io) لخدمة منصة ميناء اللوجستية بكافة وظائفها وعملياتها.

---

## 🌟 الميزات المكتملة في النظام الخلفي (Backend Features)

1. **المصادقة والأدوار الصارمة (RBAC)**:
   - الأدمن العام (`SUPER_ADMIN`)
   - مزود الخدمة اللوجستية (`PROVIDER`)
   - المستورد / العميل (`IMPORTER`)
   - السائق (`DRIVER`)
   - حماية المسارات برمز JWT وتشفير كلمات المرور بـ Bcrypt.

2. **نظام الدفع عبر التحويل البنكي الخارجي ومراجعة الإيصالات (Bank Transfer & Escrow)**:
   - عرض حسابات المنصة البنكية الرسمية (آيبان الراجحي، الأهلي، إلخ).
   - رفع إشعار التحويل البنكي الخارجي (صورة/PDF) مع رقم العملية واسم البنك وتاريخ التحويل.
   - لوحة فحص الإيصالات للأدمن المالي.
   - اعتماد الإيصال بضغطة زر وتفعيل الشحنة وحجز المبلغ كضمان (Escrow).
   - توليد فواتير إلكترونية متوافقة مع هيئة الزكاة والضريبة والجمارك (ZATCA Phase 2 TLV QR Code).
   - تسجيل تحويل مستحقات المزود بنكياً بعد اكتمال التسليم.

3. **أسطول الشاحنات والتتبع اللحظي (Fleet & Live Telemetry)**:
   - بث مباشر لإحداثيات الـ GPS والسرعة والحرارة عبر **Socket.io**.
   - خوارزمية الرصد التلقائي لتجاوز درجات الحرارة في الشاحنات المبردة.
   - استقبال وتحديث تنبيهات الطوارئ ومعالجتها.

4. **محرك طلبات التسعير والمناقصات (RFQ & Quotations)**:
   - إنشاء طلبات تسعير للشحن (بحري، جوي، بري، تخليص جمركي).
   - تقديم المزودين لعروض أسعار منافسة.
   - قبول العرض وتحويله تلقائياً لشحنة نشطة وتوليد فاتورتها.

5. **إدارة الشحنات والمستندات الرسمية (Shipments & Documents)**:
   - بوالص الشحن (Bill of Lading)، البيانات الجمركية، الفواتير التجارية.
   - فلترة وتتبع الشحنات حسب الدور وحالة الشحنة.

6. **إدارة المنصة والعمولات والبحث الفوري (Admin & Global Search)**:
   - ضبط نسب العمولات لكل قطاع (بحري 2.5%، جوي 3%، بري 1.5%، تخليص 1%).
   - محرك بحث شامل ولحظي في الشحنات والشاحنات والمستخدمين.

## 🛠️ أوامر التشغيل والتهيئة السريعة

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تهيئة وتوليد قاعدة البيانات:
```bash
npx prisma generate
npx prisma db push
```

### 3. تغذية قاعدة البيانات بالبيانات التجريبية الكاملة:
```bash
npm run prisma:seed
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```

الخادم سيعمل مباشرة على: `http://localhost:5000`  
فحص الحالة: `http://localhost:5000/api/health`
